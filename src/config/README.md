# ตั้งค่าเว็บ (config)

> แก้ที่ไฟล์เดียว: **`src/config/site.js`**
> ⚠️ ไฟล์นี้**ไม่ใช่ secret** — ข้อมูลจะถูกฝังใน bundle และมองเห็นได้
> **ห้ามใส่ API key / token / รหัสผ่าน** ที่นี่

---

## 1. LINE ID (ปุ่ม "เพิ่มเพื่อน LINE")

```js
export const LINE_ID = ''      // ← ใส่ตรงนี้
```

**หา LINE ID ได้จาก**:
1. เปิดแอป LINE → โปรไฟล์ของตัวเอง
2. ⚙️ ตั้งค่า → โปรไฟล์ → **ID ผู้ใช้**
3. คัดลอกค่าที่ขึ้นต้นด้วย `@` (เช่น `@abc1234`)

หรือเปิดเว็บ `https://line.me/R/ti/p/@xxxxx` ในเบราว์เซอร์ → ถ้าเปิดได้แปลว่า ID ถูกต้อง

> **ถ้ายังไม่ใส่** ปุ่ม LINE จะ**ไม่แสดง** (ซ่อนอัตโนมัติ ไม่ทำให้เว็บพัง)
> ทดสอบแล้ว: ใส่ ID → ปุ่มปรากฏ · ไม่ใส่ → ปุ่มหายจาก bundle

**รูปแบบ ID ที่ใช้ได้**: ข้างในโค้ดไม่ต้องใส่ `@` (ฟ้าเติมให้เองใน URL)

## 2. ผู้สนับสนุน (แบนเนอร์)

```js
export const SPONSORS = [
  {
    name: 'ชื่อผู้สนับสนุน',        // จำเป็น
    tagline: 'คำโปรยสั้นๆ',           // ไม่บังคับ
    url: 'https://example.com',       // ลิงก์เว็บ
    image: '/sponsors/logo.png',      // โลโก้ (ใส่ไฟล์ไว้ใน public/sponsors/)
    badge: 'ผู้สนับสนุนทอง',          // ป้ายเล็กๆ มุมขวา
  },
  {
    name: 'ผู้สนับสนุนคนที่สอง',
    tagline: 'คำโปรย',
    url: 'https://example2.com',
  },
]
```

**อาร์เรย์ว่าง = ไม่แสดงแบนเนอร์** (ค่าเริ่มต้นตอนนี้คือว่าง → ยังไม่มีแบนเนอร์แสดง)

### รูปโลโก้
- ใส่ไฟล์ไว้ที่ `public/sponsors/` เช่น `public/sponsors/logo.png`
- อ้างอิงด้วย `/sponsors/logo.png` (ไม่ต้องเขียน `public/`)
- ถ้าไม่ใส่ `image` ระบบจะแสดงตัวย่อ 2 ตัวแรกของชื่อแทน
- ขนาดแนะนำ: สี่เหลี่ยมจัตุรัส ~200×200 px

### ตำแหน่งแบนเนอร์
```js
export const SPONSOR_POSITION = 'bottom'   // 'top' | 'bottom' | 'both'
```
> หมายเหตุ: ตอนนี้โค้ดวางแบนเนอร์ท้ายสุดของหน้า (หลังรายการฉบับก่อนหน้า)
> ถ้าต้องการย้ายไปใต้ header ให้แก้ใน `src/components/HomeView.jsx`

### ข้อความท้ายแบนเนอร์
```js
export const SPONSOR_FOOTER = 'สนับสนุนเราเพื่อให้บทสรุปข่าวอัปเดตทุกวัน'
```

## 3. ปุ่มแชร์

```js
export const HIDE_SHARE = false   // true = ซ่อนปุ่มแชร์ทั้งหมด
```

| ปุ่ม | ต้องใช้อะไร |
|---|---|
| แชร์ Facebook | ไม่ต้องใช้อะไร |
| เพิ่มเพื่อน LINE | ต้องใส่ `LINE_ID` |
| แชร์ (Web Share API) | ไม่ต้องใช้อะไร (มือถือ) |
| คัดลอกลิงก์ | ไม่ต้องใช้อะไร |

## 4. ปุ่ม Like

**ไม่ต้องตั้งค่าอะไร** — ใช้งานได้เลย

เก็บยอดในตาราง `article_likes` ของ Supabase

> ⚠️ **ข้อจำกัดที่ต้องรู้**: เว็บไม่มีระบบ login
> - กันกดซ้ำด้วย `voter_id` ที่เก็บใน `localStorage` ของเครื่องผู้ใช้
> - **ล้าง localStorage = กดซ้ำได้** · เปิด private mode แล้วกดซ้ำได้
> - ใครก็ INSERT ได้ แต่ **ลบ/แก้ของคนอื่นไม่ได้** (RLS ไม่ให้ UPDATE/DELETE)
> - ทดสอบแล้ว: กดซ้ำจากเครื่องเดิม → `409` ถูกกัน · พยายามลบ → ไม่มีผล

ถ้าภายหลังอยากนับ "คน" จริง ต้องเพิ่มระบบ login (Supabase Auth) — ยังไม่ทำ

## 5. Environment (ตั้งค่าแยกอีกชั้น)

อยู่ที่ `.env.local` (ไม่ขึ้น git) และ Environment Variables บน Vercel

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `VITE_SUPABASE_URL` | `https://<ref>.supabase.co` |
| `VITE_SUPABASE_ANON_KEY` | anon key (public โดย design — RLS คุมสิทธิ์) |

> **Vite อ่าน env ตอน build** → เพิ่ม env บน Vercel แล้วต้อง **Redeploy**
> **ต้องขึ้นต้นด้วย `VITE_`** → ชื่ออื่น browser มองไม่เห็น
